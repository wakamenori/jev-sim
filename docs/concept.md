# コンセプト：王位継承の側近シミュレーション

決定日：2026年9月23日。設計の履歴と現行ルールを記録する。初期の設計判断は後半の「再設計で決まったこと」で更新されている。未決定・後回しの項目は実装済みとは扱わない。実行時の人物・事実・証拠の値は[シナリオ定義](scenario.md)を参照。

## 一文で

病に倒れた王が n 日以内に後継者を指名する。プレイヤーは候補の一人に仕える側近として、宮廷の人々との相互作用を通じて自分の主人を王位に就ける。最終判定は王が行う。

## 中核となる設計判断

| 論点 | 決定 | 理由 |
| --- | --- | --- |
| プレイヤーの立場 | 候補本人でなく側近 | 正式な権力がなく「言葉と工作だけが武器」になる。主人も Jev が動かす NPC なので、主人に切られる緊張が生まれる |
| 最終判定 | 王（NPC）が候補から一人選ぶ Choice | すべての行動が「王が何を信じるか」に収束し、因果が読める |
| 王の state | 価値観（部分的に隠す）／受けた報告（報告者への信頼で重み付け）／目撃した出来事 | 王への直接説得ゲームにしない。王に届く経路を持つ人物が価値を持つ |
| NPC の駆動 | 属性（欲求・恐怖・関係・秘密・立場・性格）を言葉で渡し、Jev が判断 | 各自の合理性で動き、事後に行動を説明できる |
| 行動の入力 | 行為 × 相手 × 材料の構造化。材料は世界に実在する事実・人物・物 | 自由文は敵対的入力に弱く、因果が追えず、メモ化が効かない |
| 分布の可視性 | 全公開 | 戦略ゲーム寄り。隠されるのは属性・秘密・王の価値観・伝播経路 |
| 汚い手 | 入れる。白／灰／黒／血の階段 | 効果と露出面が比例する。発覚は乱数でなく NPC の判断の連鎖で起きる |
| 王の早期死亡 | 最初は入れない | 判定者が変わると設計が一段複雑になる |
| ライバル | 他候補の側近も同じ行動語彙で Jev が動かす | AI 対戦相手を別に作らない |
| 結末 | 二値にしない | 主人戴冠＋自分は排除、他候補戴冠＋寝返りで生存、など |

## Jev の実測から来る前提（2026-09-23）

- 社会的情報（噂・手紙）には分布が大きく動く。天候には動かない。介入は社会的情報に変換されないと波及しない
- 同じ state でも確率は ±0.05 揺れ、上位が近いと argmax が反転する。**state ハッシュによるメモ化**と**シード付き乱数によるサンプリング**が必須
- confidence は返らない。必要なら分布から自前で計算する
- 1 リクエスト約 600 トークン、400〜500ms、Gateway 表示の市場価格は 1 リクエスト約 0.00001 ドル

## 積み上げの順序

1. **干渉なしベースライン**：主人公も Jev で動かし、王が指名するまで回す。因果を追える年代記を出す ← 最初のゴール
2. 目撃者と伝播（小姓・侍女・寝室係が見たことを誰に言うか）
3. 汚い手の階段（買収・偽造・刺客）と発覚の連鎖
4. プレイヤー操作（主人公の行動を Jev から人間に置き換える）
5. UI（分布の可視化、因果の鎖の表示）

## 1 日の流れ（現行）

1. **参謀が計画を立てる（Luna）**：各陣営の側近が、自分の視点・宮廷の公開情報・事実の一覧をもとに、その日の目的と一手の並びを出す。人物と事実は列挙型で縛り、一手は Jev の選択肢と同じ鍵にする。今とれない一手はコードで弾く。
2. **3 ターンの行動（Jev）**：王以外の全員が、ターンごとに「相手と話題の組」を 1 つ選ぶ。陣営の計画は state に入り、計画に含まれる選択肢には印が付く。最終的に選ぶのは Jev で、計画に従わないこともある。1 ターン目には支持も問い直す。
3. **反応（Jev）**：行動を受けた人の反応を、支持の更新と行動の選び直し後の同じ世界から並列に問い、決まった順で書き戻す。同じターン内の連鎖は起きず、次のターンに持ち越される。
4. **王の評価（Jev）**：日の終わりに王が各候補を評価し、期限を迎えた依頼・脅しを整理する。
5. **個人の整理（Luna）**：王以外の全員が他人の支持を推測し、頭目への報告・証拠の共有・翌日の方針を決める。
6. **記録と指名**：個人の整理を適用してスナップショットを残す。最終日は、その後に王が指名する。

## 行動と、それぞれで起きること

| 行動 | 使える条件 | 相手の判断（Jev） | 世界の変化 |
| --- | --- | --- | --- |
| 伝える | 自分が知っていて、相手が知っていると分かっていない事実 | 信じるか・話し手への信頼・各候補の評価 | 相手が事実を知る。出所も伝わる |
| 説得 | 自分の推す候補がある。王への説得は王に会える人だけ | 話し手への信頼・支持を問い直す | 支持が変わりうる |
| 探る | 誰にでも | 何を漏らすか（何も漏らさないこともある） | 漏らした事実を出所つきで知る |
| 依頼 | 王に会える味方に、王がまだ知らない事実を頼む | 事実を信じるか・引き受けるか | 引き受けたら、相手の選択肢に約束として残る。実行するかは本人が選び、翌日末に失効する |
| 脅す | その秘密が暴かれて相手が困り、相手が味方でも候補本人でもない。経路（王／宮廷／相手の主人）を決める。当事者に暴くと脅すことはできない | 屈する／拒む／脅し返す／頭目に助けを求める・脅した人への信頼 | 屈すれば支持が移る。拒まれたら脅した側が実行するか決める（下の「脅しと暴露」） |
| 口止め | 自陣営の弱みで、相手が知っていると分かっている | 約束するか・頼んだ人への信頼 | 約束が相手の state に残り、話す判断の抑止になる。破られうる |
| 告発 | 自分が知っていて、まだ公になっていない事実 | 王以外の全員が、信じるか・告発者への信頼・評価 | 事実が公になり、以後は脅しに使えない。王には報告で届く |

行動は確率分布からシード付きでサンプリングする。ただし最有力の半分未満の候補は捨て、残りも上位 3 つまでにする（選択肢が数十あると、ありえない行動を頻繁に引くため。1/4 では確率 0.1 前後の自滅的な手が残った）。

## 脅しと暴露

脅しは 2 つの信念の釣り合いで効く。標的は「暴かれたらどれだけ困るか × 本当に暴かれると思うか」で、脅した側は「暴けば弱みを使い切る／暴かなければ口先だけと知られる」で判断する。

1. **脅しの中身**：要求（支持、または証拠を渡せ）、経路（王に伝える／宮廷で告発する／標的の主人に伝える）、期限（宮廷での告発は 2 日、それ以外は翌日の終わり）。王への経路は、脅す本人が王に会えるときだけ。脅す側が証拠を示せれば、標的には本物の脅しに見える。
2. **標的の応じ方**：屈する／拒む／脅し返す（相手側の秘密を知っているとき）／頭目に助けを求める（陣営に属するとき。秘密は頭目に知られる）。判断材料として、暴かれたら何が起きるか、脅した人の過去の実行と見逃し、を state に書く。
3. **拒まれた後**：脅した側の選択肢に「脅しを実行する」の印が付く。実行すれば標的は「言ったことはやる人」と覚える。期限までに実行しなければ失効し、「口先だけ」と覚える。脅し返しを受けていた場合、先に暴いた側は報復を受けうる。
4. **屈した後**：支持は移ったまま。脅した側は、王への報告を命じられる（命令）。命令を拒むと、脅しは実行の段階に戻る。
5. **暴露の結果**：公の告発で宮廷の過半数が信じたとき、または王が信じたとき、事実ごとの結果が起きる。暴かれた弱みで屈していた人は解放され、支持は脅される前に戻る（戻さないと、解放後も脅した側の陣営の計画に組み込まれる）。
6. **支持が変わったターン**：ターンの始めに支持が変わった人は、新しい立場で行動を選び直す（古い立場で選んだ手を、新しい立場のまま実行しないように）。

事実ごとの暴かれたときの結果と証拠は [scandals.md](scandals.md) にまとめてある。

## 狙うシチュエーション

秘密を「持つ（脅す）・使う（告発）・守る（口止め）・運ぶ（依頼）」の駆け引きが中心になる。

- **Tam を巡る争奪**：封蝋の手紙を見た小姓の話が Wenna 経由で広がる。出所が伝わるので、各陣営が Tam にたどり着き、報告か口止めかを競う。
- **秘密の人質交換**：互いの秘密を握った陣営は告発に踏み切れない。均衡をいつ破るかが山場になる。
- **報告の戦い**：告発しても王はその場にいない。王に会える人が、誰を、どう伝えるかが決定打になる。
- **秘密を売る者**：両方の秘密を知る Petra が、王に会える重臣を脅して動かす。
- **口止めが疑いを呼ぶ**：口止めしたこと自体が「隠したい秘密がある」という情報になる。

この組では起きないこと：嘘の告発（告発は常に真実）、見返りによる取り込み（資源がない）。報告が結末に届くかは、王の最終判断の設計に依存する。
