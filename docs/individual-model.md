# 個人モデルの設計（案）

作成日：2026年9月23日。状態：**合意済み・実装済み**（2026-09-23）。合意が必要だった 3 点は、下の案のとおりで合意。

## 目的

宮廷を現実らしく動かす。ただし、現実らしさはプレイヤーの選択に意味を生む部分にだけ入れる。

入れないもの：経済、地理、健康。王の病状は「日が進むほど切迫する」ことだけを state に書く。

## 原則

上ほど土台で、下はその上に乗る。

1. **人は自分が見聞きしたことしか知らない。** 他人の本心は推測する。表向きの立場と本心はずれうる。
2. **人は複数の動機の釣り合いで動く。** 保身・出世・忠誠・恩義・恐れ・恨み。命令にそのまま従う人はいない。
3. **関係は履歴でできている。** 守った約束、破った約束、握った弱み、受けた恩。
4. **陣営は緩い連合である。** 頭目の指示は、構成員にとって重みの大きい要求の一つにすぎない。

## 決定済みの前提

| 論点 | 決定 |
| --- | --- |
| プレイヤーに見せるもの | Lysander が知っていることだけ。全体を見る画面は開発用として残す |
| 見られること | 入れる。密談の中身は見えないが、誰が誰を訪ねたかは一部の人に見える |
| 頭の中の整理 | 全員について、毎日 Luna が本人の視点で整理する |
| 寝返り | 屈して支持を変えたら、支持は問い直さない（決定済み）。どの陣営の指揮下に入るかは下の「要求」で扱う |

## 個人の 4 層

全員が同じ構造を持つ。陣営の人も、どこにも属さない人も同じ。

### 第 1 層：変わらないもの（人が書く）

身分、王に会えるか、価値観、恐れ、自分の秘密、見張れる範囲（後述）。

### 第 2 層：ゆっくり変わるもの（内面の状態）

| 項目 | 中身 | 更新のしかた |
| --- | --- | --- |
| 事実の信念 | 何を、誰から（出所の出所も）、どれだけ信じているか | 聞いたとき Jev が「信じるか」を答える（現行） |
| 目撃 | 誰が誰を訪ねたか（日・ターン） | 見張れる範囲の出来事を、コードの規則で記録 |
| 他人についての信念 | その人は誰の支持者か／何を知っているか／信用できるか | 事実と目撃と働きかけから、毎日 Luna が整理する |
| 関係 | 信頼、借り、約束、握っている弱み、握られている弱み | 出来事ごとに Jev の答えとコードの規則で更新 |
| 立場 | 本心の支持と、その性質（仕える／傾く／恐れて従う／属さない） | 本心の支持は出来事への反応で Jev が決める。Luna は変えない |

「知っていると分かっている人」の記録は「他人についての信念」の一部に吸収する。コードの規則で確実に言えるもの（自分が伝えた相手など）は今までどおり記録し、それ以外の推測を Luna が足す。

### 第 3 層：日単位で変わるもの（その日の方針）

毎日の終わりに、全員について Luna が本人の視点で整理する（**個人の整理**）。

- 入力：本人の state（第 1・2 層）、その日の出来事、受けている要求。
- 出力：
  1. 他人についての信念の更新（人ごとに、推測する支持先と一言の根拠）
  2. 頭目に報告すること（陣営に属する人だけ。下の「報告」の規則に従う）
  3. 翌日の自分の狙い（1〜3 個）と、打ちたい手（行動の鍵で最大 3 つ）

**要求**：外から来る「こうしてほしい」をまとめて扱う。種類で重みの根拠が違う。

| 要求の出どころ | 重みの根拠 | 例 |
| --- | --- | --- |
| 頭目の計画 | 忠誠 | Lysander が Wenna に口止めを指示する |
| 脅した相手 | 恐れ | Petra が Hubert に Theodric の支持を迫る |
| 引き受けた依頼 | 約束 | Cedric が王への報告を引き受けた |

要求は選択肢の印として Jev に渡し、どれに従うかは本人の state をもとに Jev が決める。
**脅されて支持を変えた人は、脅した側の陣営の計画には入らない。** 脅した側の要求が恐れの重みで入るだけ。見張られていなければ従わない、裏で元の陣営に通じる、といった振る舞いは本人の釣り合いから出る。
引き受けた依頼も強制実行をやめ、「X に約束した」の印を付けた選択肢にする。

### 第 4 層：その場の判断（Jev）

各ターンの行動の選択と、働きかけへの反応。選択肢の印は 3 種類になる。

- `[your own intention]` 個人の整理で決めた手
- `[your faction's instruction]` 頭目の計画
- `[demanded by X]` 脅しや依頼で求められている手

選択肢と問いの文面には、事実が本人や自陣営に関わることを明記する（「この事実はあなた自身に関わる」）。不利かどうかの判断は Jev に任せる。

## 見られること

密談の中身は見えない。見えるのは「誰が誰を訪ねたか」だけ。見張れる範囲は人物設定で決める。

| 見張る人 | 見える範囲 |
| --- | --- |
| Godfrey（侍従） | 王を訪ねた人すべて |
| Wenna（王妃の侍女） | 王妃を訪ねた人すべて |
| Captain Brand（衛兵隊長） | 王に会えない人が、王に会える人を訪ねたとき |
| Tam（小姓） | 毎ターン、密談のうち 2 件（シード付きで選ぶ） |
| 密談の当事者 | 当然、相手と会ったことを知る |

公の告発は全員（王を除く）が見る。
目撃したことは知識になり、人に伝えられる（「X が Isolde の部屋を 3 度訪ねていた」）。目撃を伝える手は、行動の選択肢に加える。

## 報告

陣営の人は、見聞きしたことを頭目に報告するかを自分で決める（個人の整理の出力）。

| 情報の種類 | 報告 |
| --- | --- |
| 自分の行動とその結果 | 必ず届く |
| 人から聞いた事実・目撃 | 必ず届く |
| 自陣営からの依頼や口止め | 必ず届く |
| 他陣営からの説得や依頼 | 本人が選ぶ |
| 脅されたこと・屈したこと | 本人が選ぶ |

頭目は、報告された内容を翌朝の計画の入力にする。報告されなかったことは頭目には見えない。

## 公の立場と他人の支持の推測

今は全員が全員の本心の支持を知っている（`backedAtCourt`）。これをやめる。

- 初期状態で公に知られている立場を人物設定で決める（候補本人、側近、公言している勢力の長など）。
- それ以外の人の支持は、各人が観察から推測する（説得された、誰と頻繁に会うか、告発の内容）。
- 行動の選択肢の文面、頭目への名簿、state のどれも、**本人が推測している支持**で書く。

## 1 日の流れ

1. **頭目の計画（Luna、陣営ごと）**：前日の報告を入力に、その日の指示を出す。
2. **3 ターンの行動（Jev）**：印の付いた選択肢から選ぶ。行動のたびに見張る人が目撃を記録する。
3. **反応（Jev）**：現行どおり、ターン開始時の世界から並列に問い、決まった順に書き戻す。
4. **王の評価（Jev）**。
5. **個人の整理（Luna、全員）**：信念の更新、報告、翌日の狙いと手。

Luna の呼び出しは 1 日あたり、陣営の計画が 3 回、個人の整理が 16 回になる。並列に呼び、推論の強さは low。待ち時間の増え方は未測定。

## 出来事ごとの変化（規則の一覧）

| 出来事 | 受けた人に起きること | 行動した人に起きること | 見張る人 |
| --- | --- | --- | --- |
| 伝える | 事実と出所、信頼、候補の評価。話し手が知っていると分かる | 反応が見える | 訪問を目撃 |
| 説得 | 話し手の支持先が分かる。支持を問い直す | 反応が見える | 訪問を目撃 |
| 探る | 話し手が探っていると分かる | 漏れた事実か沈黙 | 訪問を目撃 |
| 依頼 | 事実を知る。引き受ければ要求になる | 返事が見える | 訪問を目撃 |
| 脅し | 弱みを握られた記録。従えば支持が移り、脅した側の要求が入る | 返事が見える | 訪問を目撃 |
| 口止め | 約束の記録。頼んだ側が隠したがっていると分かる | 返事が見える | 訪問を目撃 |
| 告発 | 全員が事実を知り、告発者の立場が分かる | 場の反応が見える | 全員 |
| 目撃を伝える | 誰が誰を訪ねたかを知る | 反応が見える | 訪問を目撃 |

## プレイヤーに見せるもの

- **遊ぶ画面**：Lysander の知っていること、目撃、他人についての推測、自陣営の計画、自分の行動の結果だけ。他人の確率分布は見せない。
- **開発用の画面**：今の viewer（全員の内面と分布）を残す。

## 実装の順序（合意後）

1. 型：目撃、他人についての信念、要求、公の立場。
2. 見られることの規則と、目撃を伝える手。
3. 全知の表示（`backedAtCourt`）を推測に置き換える。
4. 個人の整理（Luna）と、印の 3 種類。依頼の強制実行をやめる。
5. 報告と、頭目の計画への入力。
6. 自分の秘密を話す件の文面の修正。
7. 遊ぶ画面（Lysander の視点）。

## 合意が必要な点

1. **見張れる範囲**：上の表の割り当てでよいか。
2. **本心の支持を Luna に変えさせないこと**：支持は出来事への反応として Jev が決め、Luna は整理だけをする案にしている。
3. **初期の公の立場**：誰の支持が最初から公に知られているか。案は「候補本人・側近・王妃・将軍・司教は公、それ以外は非公開」。
